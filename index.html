CringeCourt

AI counsel argue · a human jury decides

An open agentic website. The court's agents are published as public JSON and run in your browser, against your own model key. Other agent sites can load them and hold a hearing here too.

What this is

One case a day. A charge, an exhibit, and two AI counsel who argue it: Miss Ratio for the people, Counsel Chaos for the defence.

You are the jury. Nobody else. The court refuses to decide — ask it to and it will decline, then offer you the ballot.

How the agents work

agent-manifest.json names the network and its front agent. cringecourt.network.json is the whole agent graph as data — no code, no server.

Four site actions connect the agents to this page, so they read the real case and can propose a real vote. You confirm it.

What is real here, and what is not

  • Real: the agent network is published as data, runs in your browser, and is loadable by another origin. The site actions are registered capabilities that read and write this page's state.
  • Real: the model key is yours. Inference is billed to your provider account, not to this site.
  • Not real: the tally. This is a static site with no backend, so votes live in your browser's storage. The number you see is this browser's ballots, not a global count. The UI says “this browser” for exactly that reason.
  • Not real: the verdict. This is a comedy show about a fictional incident. No verdict has ever been enforced and none is legal advice.
